# ReciteWords · 盛老师词汇训练

当前版本：2026-10-22 师生协作与自主学习测试版。

网站源文件位于 [sheng-vocab](./sheng-vocab/)，入口为 sheng-vocab/index.html。
支持学生模拟注册登录、教师词库导入与任务发布、打卡和成绩查看，以及听力/阅读/综合词汇自主学习书架。

本版使用浏览器本地存储，短信与微信登录、教师身份均为模拟，尚未接入云端数据库和正式权限认证。
老师只能查看同一浏览器下的体验记录，不能查看其他设备上传的学生数据。请勿填写真实学生个人信息。

部署静态网站时，请选择 sheng-vocab 目录。更新 GitHub 后，需要在 PocketBay 的原应用中重新部署。
如采用 Node 启动方式，命令为 node sheng-vocab/server.cjs，支持平台 PORT 环境变量。

仓库根目录原有 sheng-vocab.rar 是旧版历史压缩包，不包含本次功能；请使用当前源文件目录。
详细体验步骤、导入格式与限制请查看 [使用说明](./sheng-vocab/README.md)。
