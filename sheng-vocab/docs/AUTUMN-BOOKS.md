# 2026 年秋季词书导入

2026-11-22 将用户提供的七、八、九年级教师版 Word，分别整理为完型、阅读、写作三本，共九本。源封面为旧学年，按用户指定的新版本命名为 2026 年秋季；没有修改原始文件。

每个年级完型、阅读各 300 词 + 100 短语。写作保留三个话题的词、短语和 30 条标准句型，按英文规范键合并话题间重复项，并合并中文释义和 sources 中的话题、原序号：七年级 280 词 + 58 短语 + 30 句型，八年级 272 + 60 + 30，九年级 280 + 60 + 30。总共 3500 条。学后检测题、范文和仿写说明不重复作为词条导入。

words JSON 保留 kind、phonetic、source_document、sources、edition；单词词性参考 ECDICT 并人工补全缺失项，保留原文中英文。已有教师例句只在英文和释义均匹配时复用；未提供语境的条目不伪造例句，以词义题完成过关。短语和句子不强行加词性。句型标准答案直接采用源文档。

学习：写作分类先学习并完成 3/3/4 分段复习，随后按最多五题一批默写英文，全对才通过；错词重学。阅读保留句子选择题，源文档无例句时用中文选英文，不阻断学习。写作不展示答案选项，不开启拼写检查；字母大小写和首尾空格按既有服务端判题，句型需填写标准表达（含标点）。未改动既有阅读学习进度格式。

数据直接保存 Supabase rw_libraries，原有三本词书和学生记录保留。新书使用按版本、年级、分类生成的稳定 UUID 防止重复导入。books.json 私有导入快照在本地 outputs/autumn-books-20261122，未发布到公开 GitHub。书架由学生自行选择添加，不批量修改学生个人书架。

验证：数据库逐本 JSON 相等核对；学生角色可见全部九本；三本写作词、短语、句型正确/错误判题事务测试并回滚；浏览器写作学习和复习后默写、失败重学测试；既有五题分组及学生缓存/保存回归。

词性参考：[ECDICT](https://github.com/skywind3000/ECDICT)，MIT 许可。原文缺少逐词用法例句，后续可由教师补充，不应将词义提示冒充例句翻译。
