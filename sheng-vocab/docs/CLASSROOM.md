# 课堂过关 v1（2026-11-20）

教师首页顶部「课堂过关」；学生「班级任务」和「测单词」均有入口。
首次使用由教师选班级、词书，点击「设置课堂目标」。不自动猜测教师要考的范围。

## 规则与口径

- 教师发布每班每词书一个目标，1-based 起止序号，至少 10 条。发布时复制词书完整快照，保证后续编辑、排序不会挪动课堂成绩对应的词。调整目标范围增加 revision，保留已有过关记录；扩大范围后重新计算分母。快照不会跟随原词书编辑更新；需要新内容时制作新词书并发布新目标。
- 学生仅查看自己班级目标、本人进度。教师可切换班级和学生并代其进行课堂测试。权限由数据库成员表判断，不信任浏览器传入角色。
- 10 / 20 / 50 从目标内按词书顺序选未过关词；自选范围须至少 10 条且完全位于教师目标内。已过关自动扣除。选择集合内出题随机，选择后剩余少于 10 条可正常测试剩余词。
- 英翻中提供英文和英文例句，四个不同中文释义；中翻英提供中文与可用的中文例句，默写英文。两种模式独立计数。
- 每组最多 5 题，全对才将该组全部词条标记过关。答错的一组暂不记过关，重学错词后重新测试同一组。尾组按实际数量全对即可。测试不自动播放目标英文，避免默写答案被朗读；重学词卡可点击播放，答错朗读词与例句。
- 教师认定保留 source=teacher、操作者和时间；可撤销教师认定，不覆盖已有 test 来源记录。认定操作幂等。教师标记与测试通过不重复计数。教师认定后又实际测试通过的词升级为 test 来源，避免撤销认定误删实测成绩。
- 词条过关率 = 当前目标内、该模式去重过关词条数 / 当前目标词条数。班级词条率分母 = 当前班级学生数 × 目标词条数；全部过关人数为该目标该模式词条全部过关的学生数。
- 课堂过关是单独的课堂成绩，不自动并入旧「词书掌握度」或「今日已学」统计。原学习与复习记录不改写。
- 本机保存未完成测试、答案、提交 UUID（按账号与环境隔离）。云端按整组确认保存，失败可相同编号重试。已通过组在跨设备刷新后可见；未提交的单题进度仅保留在当前浏览器。退出课堂不退出账号。

## API 与数据迁移

单一可复用 RPC `rw_classroom(p_action,p_payload)`，公开函数是 invoker，调用私有 schema 内的授权实现。每个请求重新检查登录成员、学生首次改密、班级归属和目标版本。

操作：catalog / detail / set_goal / mark / unmark / begin / resume / submit。
稳定字段：UUID、ISO timestamptz、reading/writing 模式、1-based word_index、revision。

新增业务表：

| 表 | 含义 |
|---|---|
| rw_class_goals | 班级词书目标、完整词书快照、范围与版本 |
| rw_class_passes | goal + student + mode + word_index 唯一过关记录 |
| rw_class_sessions | actor、学生、题目快照、随机题序、下一组偏移 |
| rw_class_events | 认定、撤销、范围变更与测试提交审计；提交 ID 唯一 |

四张表启用 RLS，不授予 anon/authenticated 直接表权限。只由经过角色检查的私有实现读写。顾问提示的四项 `rls_enabled_no_policy` 是封闭 API 存储设计，并非公开可读。
备份脚本导出格式升级 schema_version=2，包含上述表；仍可验证旧 v1 导出。Auth 备份与恢复仍单独进行。完整结构见 classroom.sql，按 UUID/FK 次序恢复。

## 验证

- tests/classroom-db.sql：事务回滚验证角色隔离、范围限制、服务端判分、仅全对记分、幂等提交、两种模式隔离、教师认定/撤销、最后 2 词、写作大小写空白归一化、过期版本拒绝、真实 authenticated 角色 RPC 可执行、匿名与直接表权限拒绝。
- tests/classroom.cjs：教师/学生入口、320×568 和 390×780 设置布局、认定/撤销、错组重学再测、响应丢失原编号重试、返回后恢复题号、默写题型。
- 现有缓存、教师词书发布、学生栏目切换回归测试。
- 无测试数据留在真实成绩表；未替教师创建课堂目标。

限制：这是课堂练习，不是防作弊考试。客户端能看到词书与本题答案用于即时反馈；最终组成绩由服务端校验。超长词句、系统放大字体或软键盘占用屏幕时允许卡片内滚动以保持可读，普通手机设置页保持紧凑单屏。
