# 每周班级任务

教师首页「每周任务」选择课堂目标、周一、词汇范围及学习/复习/词形转换类型；系统按序分到周一至周五。先在「课堂过关」设置该班词书和范围。重复发布同班、同周、同目标、同类型、同题型、同范围只生成一份。发布后不自动改动已有任务。

学生默认只展开当天任务；其他日期和遗漏任务折叠。点击任务进入对应词书、范围和题型的过关界面。未来任务在服务端锁定。每组最多五题，全对才保存进度，不足五题测试实际剩余词汇，不补入未安排词汇。答错进入错词重学再重测。未完成作答保存在本机；云端保存失败重用事件编号重试。

周目标百分比 = 本目标各日已过关条目数 / 各日安排条目数，向下取整。任务全部条目通过才划线。复习任务要求本次作答，不能用历史课堂通过或教师认定代替。不同日期复习同词分别计算任务完成度，不能解读为去重词汇量。词形转换使用中文提示与英文标准答案，强制默写题型。

数据库：weekly.sql 新增 rw_weekly_targets、rw_weekly_items、rw_weekly_checks，rw_class_sessions 增加 weekly_item。public.rw_weekly 为 invoker 包装，rw_private.weekly 验证身份、首次改密、教师角色、学生班级和日期；数据库触发器仅在原有课堂判题成功推进 session 时记账。前端不能直接写完成状态。目标表保留 UUID、序号、日期，关系与数据可迁移。

业务导出格式升级 schema_version=3，包含新三表和会话关联，仍可验证 v1/v2 文件。业务导出不包含 Auth 密码/密钥，身份系统需单独迁移。账号 Excel 属于私有交付，不进入公开仓库。

验证：tests/weekly-db.sql 事务回滚验证五天拆分、重复发布、权限、历史过关不抵复习、失败不记账、成功幂等、未来锁定；tests/weekly.cjs 验证手机布局、入口路由、断点续答、保存响应丢失、完成返回刷新、教师发布。已有课堂、学生缓存及教师导入回归同样执行。
