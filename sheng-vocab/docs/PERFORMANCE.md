# 本次性能检查（2026-11-06）

## 结论与边界

已检查 pg_stat_statements、带真实 authenticated 角色和 RLS 的 EXPLAIN ANALYZE，以及索引和 advisories。样本小，耗时包括冷/热缓存、函数初次规划的波动；不是并发压测，不用于宣称能支持多少人。

历史 API 聚合样本：学生概况 111 次，数据库平均 10.86ms、最大 69.10ms；学习判题 108 次，平均 6.33ms、最大 51.38ms；掌握度目录 6 次，平均 56.76ms、最大 86.71ms；开始测评仅 2 次，平均约148ms。均不包含国内到孟买的网络往返。现阶段没有升级资源的测量依据。

## 已调整

- 3 本词库旧列表（含完整 words）的 JSON 为 51,628 bytes；新目录 JSON 为 585 bytes，减少约98.9%。这是数据库序列化值比较，非压缩后的 HTTP 字节统计。
- 学生首次访问四栏目共12个数据请求（模拟固定数据）；缓存有效且没有写入时，第二轮切换新增0个。测试覆盖动态加载栏目模块、单本内容延迟加载。
- 教师目录同样只取元数据，详情/发布时才获取目标词库。
- 已完成任务由数据库聚合、每页30条，不再逐页拉取全部 progress 再由浏览器统计。
- 作答先反馈，网络期间显示保存状态；成功后推进。失败同 ID 重试，本机待保存记录可跨页面恢复。
- 增加 `rw_answers(student,at desc)`、`rw_progress(user_id,learned_on desc,task_id,word_index)`，补齐 progress.task_id 与 bookshelf.library 外键索引。
- 保留已存在的 review(student,due_at)、book/group test(student,at desc) 索引，避免重复。
- review 与 teacher-library RLS 将 auth.uid 改为 InitPlan 子查询，权限含义保持一致。
