# 本次开发说明

基于 GitHub main 提交 a0a9be0d4848824b8b7374c75a3b49ecbd960309。原始下载包保留在工作目录，仓库内 rar 保留。

技术栈：原生 HTML/CSS/JavaScript，Node.js 静态服务器，无第三方运行依赖。
已有：学生体验登录、单词卡与测试、词库导入、自主书架、任务发布、打卡、成绩与教师统计。
缺失：真实认证、服务端权限、跨设备数据同步、多班级云数据库。当前仍是本机体验版。

修复：局域网 HTTP 下 randomUUID 不可用时改用 getRandomValues 生成编号；中文 CSV 模板加入服务器白名单；服务器增加请求方法限制、读取错误处理、启动错误提示，默认只监听本机。

运行：安装 Node.js 后，在本目录运行 node server.cjs，浏览器打开 http://127.0.0.1:4173。局域网演示可运行 HOST=0.0.0.0 node server.cjs，但每台设备数据仍独立。

测试：全部脚本语法通过；兼容分支1000个编号无重复。HTTP集成测试在当前工具环境超时，浏览器交互尚未验证，不能宣称完整验收。

建议验收：老师导入至少4个不同释义的单词→发布任务→切换学生完成全部卡片→参加测试→切回老师查看打卡与成绩；再测试自主书架。

下一步：为网页与小程序建立共享 API，接入真实账号、班级成员权限与数据库；服务端计算成绩并保存提交记录，完成两台设备互通测试后再让40名学生试用。
