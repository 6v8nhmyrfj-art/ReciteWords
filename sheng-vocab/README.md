# 盛老师词汇训练 · 手机网页体验版

双击 index.html 可直接体验。也可在本目录运行 `node server.cjs`，打开 http://127.0.0.1:4173。

包含：20 词演示词库、学习卡片、自动英文发音、掌握程度记录、断点续学、生词复习、随机 10 题测试、90% 达标判断、错题及历史成绩、本地昵称。

每次用户点击进入学习或切换单词时，使用 Web Speech API 自动朗读英文。依赖设备英文语音与浏览器支持，某些微信/手机浏览器会限制播放，页面提供实际状态与重听入口。测试不朗读答案。

数据只存储在当前浏览器 localStorage 中，不跨设备同步；清理浏览器数据后会丢失。没有云端、真实登录、教师端或正式班级功能。

所有页面资源位于本目录，不加载外部字体或脚本。手机布局自适应；桌面保留居中偏右的手机宽度预览。
