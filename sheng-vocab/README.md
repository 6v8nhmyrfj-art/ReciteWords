# 师生协作 · 第一个本地测试版本

本地启动：在本目录运行 node server.cjs，打开 http://127.0.0.1:4173 。也支持通过 PORT 环境变量指定端口。
也可双击 index.html，文件方式和网页方式的数据不互通。

## 推荐体验顺序
1. 首页点“老师体验”，进入班级概览。示例·小明、小红、小李是明确标注的演示数据。
2. 单词库：下载 CSV 模板或从 Excel 复制表格粘贴，检查并预览，确认保存。
3. 学习任务：选择词库、任务名称、截止日期、过关分数，发布到体验班级。
4. 切换学生体验：选任务、完成一轮学习、参加测试。
5. 切回老师体验：看打卡、过关名单和学生详情，支持搜索、筛选和导出 CSV。

## 导入
支持 UTF-8 CSV 文件和 Excel 复制的制表符表格；不直接解析 .xlsx 文件。
表头至少包含“单词”和“中文释义”，可选音标、词性、例句、例句翻译。
缺少必填数据时阻止保存；重复英文单词忽略大小写，保留第一条并提示。
每次最多 2000 行、文件最大 2 MB；发布选择题任务至少要 4 个单词和 4 种中文释义。
词库可修改中文释义；已发布任务保存独立快照，后续修改不会改变已有任务和成绩。

## 打卡与成绩
每个学生、每个任务分别保存。北京时间当天完成全部单词一轮学习算打卡，
只登录或做部分练习不算。测试按任务设定分数判断过关，默认 90%。
未开始、学习中、待过关、已过关分别展示。过关使用任务历史最高成绩，
最近成绩单列，避免重测低分抹去已过关记录。打卡与测试过关相互独立。
截止日期用于任务提示，本版不禁止逾期学习；不提供缺勤或处罚判断。

## 限制与发布状态
数据仅保存在同一浏览器和同一网址下，没有跨设备同步；清理浏览器数据会丢失。
老师页能看同一浏览器产生的记录，不能看到其他学生手机的数据。
示例学生仍计入演示统计，所有示例行和本机体验账号都标明来源。
本版只有一个体验班级，没有正式教师审批、班级权限、云数据库或服务端认证。
请勿录入真实学生个人信息。本地存储和身份切换不构成安全边界。
正式版必须接入真实身份认证、服务器权限校验和数据库，然后才能给学生使用。
这是 2026-10-22 的师生协作与自主学习测试版。代码更新到 GitHub 不代表 PocketBay 已重新部署；部署时请使用当前 sheng-vocab 文件夹。

## 验证
脚本语法检查；浏览器验证导入错误和重复项、CSV/Excel粘贴、发布、
学生任务接收、完整学习打卡、75%边界过关、老师统计、筛选、历史记录、
名单导出，以及修改词库后不影响已发布任务。

## 自主学习书架更新
学生端增加“自主学习”入口，支持综合词汇、听力专项、阅读专项分类、搜索和选书。
词库书由老师导入，填写分类与介绍，并勾选是否开放到自主学习书架。
现有词库可以从“查看词库”调整开放状态；关闭不会删除学习记录，重新开放可以续学。
自主学习不需要发布班级任务；每本书单独保存个人学习、复习与测试记录。
自主学习进度、完成日期与成绩不计入班级任务的打卡或过关统计。
听力与阅读是词汇书分类，本版练习仍为单词卡、设备发音和词义测试，未包含听力试卷或阅读文章。
示例听力书、阅读书来自现有示例词汇，并已标注“示例”。
已验证：老师导入后直接开放、分类与搜索、选书学习、自主测试100%成绩、
班级任务数据隔离、关闭后隐藏以及重新开放后保留学习进度。
